JARVIS — Shell Ambient

Orb overlay, toast, command bar, panel baki, dan dua overlay. Semua jendela frameless, transparan, dan selalu di atas — digambar apa adanya di atas desktop pengguna.

Lembar ini melanjutkan jarvis-design-system.html (22 artboard) dengan token yang sama, tanpa mengubah artboard lama. Artboard 1–6 adalah shell Fase 1; 23–28 adalah keadaan yang menentukan (fokus, senyap, konfirmasi risiko, riwayat, izin, tema terang).

Asumsi

#AsumsiAlasan
A1Orb 56 px digambar pada 1280×720 tanpa penskalaan DPI.Spesifikasi menyebut 56 px dan target sentuh 44 px; keduanya sudah terpenuhi pada 100%. Pada 150% DPI orb harus ikut token, bukan piksel tetap.
A2Lima jendela digambar sebagai overlay transparan di atas desktop contoh.Spesifikasi menyebut frameless/transparan/always-on-top. Desktop contoh dipakai supaya glow dan keterbacaan bisa dinilai; bukan bagian dari produk.
A3Toast memakai tinggi 96 px (dua tombol) atau 74 px (tanpa tombol).Spesifikasi hanya memberi angka 8 detik dan batas antrean; tinggi mengikuti isi.
A4Panel baki memakai 460×660, bukan 460×640.Tiga baris izin ditambah input membutuhkan 20 px tambahan; pada 640 px input menabrak baris izin terakhir.
A5Tingkat risiko sedang/berisiko memakai amber, bukan merah.Spesifikasi hanya menyediakan cyan dan amber. Bahaya dibedakan lewat bentuk: garis kiri 3 px, label teks, dan dialog konfirmasi terpisah.
A6Halaman katalog komponen (Fase 0) tidak digambar terpisah.Artboard 5, 23, 27 dan 28 sudah memuat toggle, tombol pil, chip, segmented, slider, kbd dan kartu dalam keadaan nyata; katalog statis akan menduplikasinya.

Peringatan yang perlu keputusan Anda

Spesifikasi ini adalah aplikasi baru: Tauri 2 + React + TypeScript, sedangkan repo ini 354 berkas Python + PyQt6 dengan Cargo.toml dan package.json yang tidak ada. Mockup tetap valid untuk keduanya karena murni visual, tetapi menulis ulang shell adalah proyek tersendiri — bukan bagian dari lembar ini dan tidak boleh dicampur dengan Fase 1.
